## Advanced Data Analysis & Business KPI Dashboard
### Project Overview
This project focuses on analyzing Superstore sales data using SQL, Microsoft Excel, and Power BI. The objective is to explore sales performance, summarize business data, calculate available KPIs, and develop meaningful insights to support business decision-making.
### Objectives
- Analyze sales data using SQL queries.
- Perform category-wise and region-wise sales analysis.
- Summarize sales by sub-category and customer segment.
- Practice SQL aggregate functions, GROUP BY, and ORDER BY.
- Use Excel PivotTables and KPI calculations.
- Develop a Power BI dashboard for business reporting.
### Tools & Technologies
- PostgreSQL
- SQL
- Microsoft Excel
- Microsoft Power BI
### Dataset
The project uses Superstore sales data containing fields such as order date, customer details, region, product category, sub-category, and sales.
### SQL Analysis
The following analyses were performed using PostgreSQL:
1. Sales by Category
2. Sales by Region
3. Sales by Sub-Category
4. Sales by Segment
5. Monthly Sales Trend
6. Top 10 Customers by Sales
SQL concepts used include:
- `SELECT`
- `SUM()`
- `GROUP BY`
- `ORDER BY`
- `ROUND()`
- `LIMIT`
### Excel Analysis
Excel was used to summarize sales performance using PivotTables and KPI calculations.
Planned KPI metrics include:
- Total Sales
- Total Orders
- Total Customers
- Total Products
- Average Order Value
- Region-wise Sales
- Category-wise Sales
### Power BI Dashboard
The dashboard is designed to present key sales metrics and visual insights through:
- KPI Cards
- Category-wise Sales Chart
- Region-wise Sales Chart
- Sub-Category Sales Chart
- Monthly Sales Trend, where date data is available
- Interactive filters for Region and Category
### Business Insights
The analysis helps identify high-performing categories, compare regional sales performance, understand sub-category contributions, and highlight customers with the highest sales.
Final business insights should be based on the verified SQL results and completed dashboard.
## Data Limitation
The current SQL table does not contain a verified `profit` column. Therefore, profit analysis and profit-margin calculations have not been included. These metrics can be added if a valid profit field becomes available.
### Conclusion
This task provides practical experience in SQL-based sales analysis, Excel reporting, KPI calculations, and Power BI dashboard development. It demonstrates how data analysis tools can transform sales records into useful business insights.
